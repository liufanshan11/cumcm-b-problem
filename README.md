# CUMCM B Problem Skill

专门面向**全国大学生数学建模竞赛本科组 B 题**的建模与论文成稿 Skill。

## 我们的优势

- **只做 B 题**：围绕近五年 B 题稳定规律设计，不做泛化的“万能数模模板”。
- **先建模，再算法**：优先机理、几何、统计与结构化简，避免为了高级而堆智能算法。
- **论文呈现优先**：内置摘要、模型总括方程组、overview 图、图表设计和 25–29 页论文节奏规范。
- **专家背书**：吸收数模专家薛毅讲评、评委真实评分细则与优秀范文的稳定偏好，但始终以当前赛题为最高依据。
- **强调创新的有效性**：创新优先落在定义、结构、修正、不确定性和验证，而不是算法改名。
- **完整工程交付**：支持 LaTeX、figures、code、PDF 编译与提交前自动检查。

## 适用任务

- 新 B 题从读题到完整建模
- 四问模型设计、算法选择与验证
- 优秀论文式叙事与图表呈现
- 结合评分细则/专家讲评优化方案
- 生成完整 CUMCM LaTeX + Code 工程
- 赛前论文终检与改稿
