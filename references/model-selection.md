## 1. 选择原则

按以下顺序选方法：

1. 数据生成机制/物理机理匹配
2. 数学结构匹配
3. 可解释性
4. 可验证性
5. 计算效率
6. 算法复杂度

不要反过来从“会什么算法”寻找问题。

## 2. 高频结构与首选方法

| 问题结构 | 首选方法 | 常见增强 |
|---|---|---|
| 有限总体抽检 | 超几何/精确检验 | OC 曲线、序贯抽样 |
| 大总体次品率 | 二项、置信区间 | Beta-Binomial、Bayes |
| 多因素实验 | 回归、ANOVA | 响应面、稳健回归 |
| 几何定位 | 解析几何、三角、向量 | 非线性最小二乘 |
| 参数反演 | 最小二乘、求根 | 多初值、Bootstrap |
| 多阶段决策 | 期望收益、动态规划 | MDP、策略剪枝 |
| 小规模离散决策 | 完整枚举 | 支配关系、剪枝 |
| 大规模离散优化 | MILP、DP、图搜索 | GA/SA/PSO 作为补充 |
| 曲面/空间覆盖 | 局部几何 + 优化 | 分区、插值、路径规划 |
| 随机系统 | 概率递推 | Monte Carlo |
| 信号周期/峰谷 | 平滑、FFT、峰值 | 物理约束拟合 |

## 3. 何时使用高级算法

### 可以使用

- 搜索空间大且离散；
- 非凸、多峰、不可导；
- 精确方法成本过高；
- 需要独立验证主算法；
- 题目明确具有预测/分类本质。

### 不应使用

- 目标函数/约束尚未定义清楚；
- 小规模可以完整枚举；
- 存在明显解析解；
- 只是为了“创新”；
- 训练数据量不足却使用复杂机器学习。

## 4. 创新优先级

从高到低优先寻找：

1. **定义创新**：场景变化后重新定义关键量。
2. **结构创新**：利用支配、对称、DAG、分解、状态压缩降低复杂度。
3. **模型修正**：用可量化证据触发复杂模型。
4. **不确定性创新**：把参数误差传播到最终决策。
5. **验证创新**：设计独立计算链交叉验证。
6. **算法创新**：只有确实解决计算瓶颈时才做。

全篇通常保留 1–3 个真正贡献即可。

## 5. 常见错误

- 相关系数直接当因果结论。
- 小样本无条件正态近似。
- 直接把附件全部数据丢入模型，不判断异常和物理有效区间。
- 优化题没有统一目标函数。
- 灵敏度只机械做 ±5%。
- 用 GA/PSO 掩盖目标或约束定义错误。
- 只给 R²，不检查残差、外推和参数意义。
