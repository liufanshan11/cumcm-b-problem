# B 题论文终检清单

## 数学正确性

- [ ] 所有变量第一次出现时已定义。
- [ ] 单位一致。
- [ ] 基础公式可从题面/机理推导。
- [ ] 近似条件明确。
- [ ] 目标函数和约束完整。
- [ ] 数值结果数量级合理。
- [ ] 关键模型有集中方程组/模型块。

## 四问递进

- [ ] 问题二说明与问题一的联系。
- [ ] 问题三尽量推广/优化前面模型。
- [ ] 问题四优先处理现实修正、不确定性或一般化。
- [ ] 符号和口径没有随问题切换而悄悄改变。

## 算法

- [ ] 说明为什么选择该算法。
- [ ] 小规模问题没有滥用启发式算法。
- [ ] 高级算法确实解决了计算瓶颈。
- [ ] 有停止条件、参数设置和必要复杂度说明。

## 验证

- [ ] 至少两类验证。
- [ ] 灵敏度分析有真实参数意义。
- [ ] 如果存在策略切换，给出阈值或稳定区间。
- [ ] M0 到 M1 的复杂化有必要性证据。

## 摘要

- [ ] 摘要+关键词不超过一页。
- [ ] 首段说明动机和总体思路。
- [ ] 每问都有动机、方法、核心结果。
- [ ] 不堆算法名和大量数字。
- [ ] 关键模型/结果适度加粗。
- [ ] 不使用“针对问题一——”破折号格式。

## 图表

- [ ] Overview 图无重叠、能展示模型与信息递进。
- [ ] 重要图不是只有黑白灰。
- [ ] 配色低饱和且全文语义一致。
- [ ] 坐标、单位、图例完整。
- [ ] 最终方案有独立总结图或表。
- [ ] 图表在正文中被解释，不是只引用编号。

## 页面与排版

- [ ] 默认主论文 25–29 页，或满足用户/当年官方要求。
- [ ] 没有通过空白、巨图、重复文字凑页数。
- [ ] 章节层级统一。
- [ ] 公式编号和交叉引用正确。
- [ ] 没有 Overfull/Undefined references。

## 可复现性

- [ ] code/ 存在。
- [ ] 关键结果可由代码重现。
- [ ] 图表由代码或可追溯数据生成。
- [ ] 附件数据路径没有写死到开发机临时目录。
- [ ] README/注释能说明如何运行。
